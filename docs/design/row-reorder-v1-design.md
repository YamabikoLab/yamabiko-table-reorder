# Row Reorder v1 基本設計書

## 1. 目的

本書は、正式v1の行並び替えについて、利用者から見える画面、操作、状態、メッセージ、振る舞いを定義する。

並び替えモードの入口、初回案内、共通のDnD表示、確定・キャンセル、安全な終了、Undo、対応Table Block、大規模Tableに関する共通設計は`reorder-v1-design.md`で定義する。

Keyboard操作、ドラッグを必要としない操作、focus、announcement、支援技術への情報提供など、別要件として扱うアクセシビリティ設計は本書の対象外とする。

## 2. 行並び替えの対象

行並び替えモードでは、対応するTableの`tbody`の行だけを並び替え対象として操作できる。

利用者が行並び替えモードを選択している間は、列の並び替え操作は開始しない。

並び替えが成立した場合は、`tbody`内の行順だけを変更する。セル内容、属性、装飾その他の保持すべき情報は変更しない。

## 3. 結合セルにより移動できない行

`rowspan`による結合範囲に含まれるため行単位では移動できない行からDnDを開始しようとした場合は、DnDを開始しない。

PCとタッチ端末の両方で、Tableのツールバーの下に次のメッセージを表示し、移動できない理由を確認できるようにする。

- 日本語: `セルが結合されているため、移動できません。`
- English: `Cannot move because cells are merged.`

移動不可メッセージは、利用者が内容を確認できる時間だけ表示し、数秒後に自動的に終了する。

`colspan`だけを含み、行単位で移動しても`tbody`の構造を壊さない行にはこの制限を適用しない。

このメッセージは、移動対象そのものを選べないためDnDを開始できない場合のフィードバックとする。DnD開始後に移動先が無効となる場合は、6の移動先の規則に従う。

移動できない行からDnDを開始しようとした場合は、Tableのデータを変更しない。

メッセージの表示に使う具体的なUI部品は本書では規定しない。

## 4. PCでのDnD

行並び替えモード中に、利用者が`tbody`の行そのものからドラッグを開始すると、その行を移動対象として扱う。

DnDが開始されたら移動対象の行を線で囲む。ドラッグ中は、`tbody`内の有効な移動先となる行間に水平の挿入線を表示する。

有効な移動先でドロップすると、その位置へ行を移動する。

## 5. タッチ端末でのDnD

行並び替えモード中は、`tbody`の行そのものを並び替え対象として操作する。

並び替えを開始していない通常操作では、Tableや編集画面を通常どおりスクロールできるようにする。

`tbody`の行からDnDを開始した後は、移動対象の行を線で囲み、`tbody`内の有効な移動先となる行間に水平の挿入線を表示する。

有効な移動先で操作を完了すると、その位置へ行を移動する。

## 6. DnD中の表示と移動先

ドラッグ中の行は、元のTable上にあるときの大きさとセルの配置関係を保って表示する。

空のセルを含んでいても、行全体の横幅や各セルの幅が不自然に縮まないようにする。また、ドラッグ中の行がTableの横方向から不必要にはみ出さないようにする。

現在の有効な移動先を、`tbody`内の行間に水平の挿入線で示す。移動先が変わると、挿入線も現在の移動先へ移る。

`tbody`内の構造を保てる位置だけを有効な移動先として扱う。結合セルなどのために移動すると`tbody`の構造が成立しなくなる位置では、確定可能な移動先を示す挿入線を表示せず、並び替えを確定しない。

移動先が変わった場合は、移動対象が入る空間を空けるように、表示位置が変わる周囲の行を滑らかに移動させる。位置が変わらない行は、この移動に合わせて一斉に動かさない。

## 7. 自動スクロール

Tableが画面内に収まらない場合でも、行の移動方向に沿って並び替えを続けられるようにする。

行のDnD中は、行の移動に必要な縦方向だけを自動スクロールし、横方向には自動スクロールしない。

DnDを開始していない通常状態では、この制限を適用せず、Tableや編集画面を通常どおりスクロールできるようにする。

## 8. 並び替え後の状態

行の並び替えが成立した場合、`tbody`内の行順だけを変更する。

セル内容がテキスト、画像、RichTextその他の内容であっても、行並び替えの扱いは変えない。セル内容そのものは変更せず、行の位置だけを変更する。

確定、キャンセル、安全な終了、Undoに関する共通の振る舞いは`reorder-v1-design.md`に従う。
