# Reorder v1 基本設計書

## 1. 目的

本書は、`docs/requirements/reorder-v1-requirements.md` および `docs/requirements/reorder-v1-quality-requirements.md` で定義した正式 v1 の要件を、利用者から見える画面、操作、状態、メッセージ、振る舞いとして具体化する。

Keyboard 操作、ドラッグを必要としない操作、focus、announcement、支援技術への情報提供など、別要件として扱うアクセシビリティ設計は本書の対象外とする。

## 2. 基本方針

- 通常の Table 編集と並び替え操作を、利用者が見分けられるようにする。
- 「行を並び替え」と「列を並び替え」の 2 つの明示的な並び替えモードを設ける。
- 行の並び替えと列の並び替えを、利用者が見分けられるようにする。
- 行並び替えモード中は `tbody` の行、列並び替えモード中は Table 全体の列を並び替え対象として操作できるようにする。
- DnD 開始時は、現在の移動対象を線で囲み、DnD が開始されたことと移動対象を確認できるようにする。
- 行・列の並び替えはセル内容の種類に依存せず、内容そのものを変更せずに位置だけを変更する。
- DnD 中は、現在どこへ移動する操作なのかを挿入線で確認できるようにする。
- DnD 中は Table 上の実際の順番を変更せず、移動対象、移動先、周囲の行・列の表示を更新する。
- 移動先が変わった場合は、移動対象が入る空間を空けるように、位置が変わる周囲の行・列を滑らかに移動させる。
- ドラッグ中の行・列は、元の Table 上での大きさと配置関係を保って表示する。
- 行の DnD では縦方向、列の DnD では横方向だけを移動のための自動スクロール対象とする。
- 行 DnD では `tbody` 内、列 DnD では Table 全体の構造を壊す移動先で、並び替えを成立させない。
- 並び替えが成立した場合だけ Table の順序を更新する。

## 3. 並び替えモードと入口

通常時は Table の編集を行う状態とし、並び替え操作は有効にしない。

Table のツールバーに「行を並び替え」と「列を並び替え」の入口を表示する。これらは並び替えモードへ切り替えるための操作であり、ドラッグ対象となる handle ではない。

「行を並び替え」を選択すると行並び替えモードになり、`tbody` の行そのものを並び替え対象として操作できる。「列を並び替え」を選択すると列並び替えモードになり、Table 全体の列そのものを並び替え対象として操作できる。

選択中の並び替え入口は、利用者が現在のモードを確認できるよう、通常時と明確に区別できる選択状態として視覚的に強調する。「行を並び替え」と「列を並び替え」は排他的に選択し、一方を選択した場合はもう一方を非選択状態にする。行並び替えモードと列並び替えモードを切り替えた場合は、選択した側のモードへ切り替わる。並び替えモードを終了すると通常の Table 編集へ戻り、どちらの入口も非選択状態にする。

各入口には、次のツールチップを表示する。

| 入口 | 日本語 | English |
| --- | --- | --- |
| 行並び替えモード | 行を並び替え | Reorder rows |
| 列並び替えモード | 列を並び替え | Reorder columns |

### 3.1 初回案内

初めて利用する人が行・列を並び替えられることを認識できるよう、初回案内を表示する。

PC では、Table にポインターを重ねた場合、Table がフォーカスされた場合、またはセル編集が開始された場合に、その操作環境で初回案内がまだ表示されていなければ、Table のツールバーの下に案内を表示する。

タッチ端末では、Table がフォーカスされた場合、またはセル編集が開始された場合に、その操作環境で初回案内がまだ表示されていなければ、Table のツールバーの下に案内を表示する。

PC では、Table からポインターが外れたことだけでは初回案内を終了しない。

初回案内は、利用者について PC とタッチ端末のそれぞれで一度だけ表示する。PC で初回案内を表示済みであっても、タッチ端末で初めて利用する場合は初回案内を表示する。

案内文は次のとおりとする。

- 日本語: `行と列を並び替えられます。`
- English: `Reorder rows and columns.`

初回案内の表示中は、「行を並び替え」と「列を並び替え」の両方の入口を通常時より視覚的に強調し、利用者がどこから並び替えを開始できるか確認できるようにする。

利用者が「行を並び替え」または「列を並び替え」を選択した場合、または初回案内を閉じた場合は、初回案内と入口の強調表示を終了し、その操作環境では表示済みとして扱う。

初回案内は通常のセル編集を妨げない。どの操作箇所へ focus を移すかなど、focus の具体的な扱いはアクセシビリティ設計で定義する。

### 3.2 再案内

初回案内を表示済みでも、利用者が並び替え機能を忘れている可能性があり、通常編集状態で行または列を移動しようとしていると判断できる操作が繰り返された場合は、並び替えの入口を再案内する。

再案内の契機は、セル内容の編集、文字選択、通常スクロールなどとして成立しない、行または列を移動しようとするドラッグ操作が、同じ行または列の付近で短時間に繰り返された場合とする。一度だけの短いドラッグや通常の編集操作では再案内しない。

再案内では、Table のツールバーの下に案内を表示し、「行を並び替え」と「列を並び替え」の入口を確認できるようにする。

再案内は通常の Table 編集を妨げず、同じ状況で過度に繰り返し表示しない。

### 3.3 結合セルにより移動できない行・列

行並び替えモード中に、`rowspan` による結合範囲に含まれるため行単位では移動できない行から DnD を開始しようとした場合は、DnD を開始しない。

列並び替えモード中に、`colspan` による結合範囲に含まれるため列単位では移動できない列から DnD を開始しようとした場合も、DnD を開始しない。

いずれの場合も、PC とタッチ端末の両方で、Table のツールバーの下に次のメッセージを表示し、移動できない理由を確認できるようにする。

- 日本語: `セルが結合されているため、移動できません。`
- English: `Cannot move because cells are merged.`

移動不可メッセージは、利用者が内容を確認できる時間だけ表示し、数秒後に自動的に終了する。

行並び替えでは、`colspan` だけを含み、行単位で移動しても `tbody` の構造を壊さない行にはこの制限を適用しない。列並び替えでは、`rowspan` だけを含み、列単位で移動しても Table 全体の構造を壊さない列にはこの制限を適用しない。

このメッセージは、移動対象そのものを選べないため DnD を開始できない場合のフィードバックとする。DnD を開始した後に移動先が無効となる場合は、6.2 の移動先の規則に従う。

移動できない行または列から DnD を開始しようとした場合は、Table のデータを変更しない。

メッセージの表示に使う具体的な UI 部品は本書では規定しない。

## 4. PC での DnD

### 4.1 行

行並び替えモード中に、利用者が `tbody` の行そのものからドラッグを開始すると、その行を移動対象として扱う。

DnD が開始されたら移動対象の行を線で囲む。ドラッグ中は、`tbody` 内の有効な移動先となる行間に水平の挿入線を表示する。有効な移動先でドロップすると、その位置へ行を移動する。

### 4.2 列

列並び替えモード中に、利用者が Table 全体の列そのものからドラッグを開始すると、その列を移動対象として扱う。

DnD が開始されたら移動対象の列を線で囲む。ドラッグ中は、Table 全体の有効な移動先となる列間に垂直の挿入線を表示する。有効な移動先でドロップすると、その位置へ列を移動する。

## 5. タッチ端末での DnD

### 5.1 行

行並び替えモード中は、`tbody` の行そのものを並び替え対象として操作する。

並び替えを開始していない通常操作では、Table や編集画面を通常どおりスクロールできるようにする。`tbody` の行から DnD を開始した後は、移動対象の行を線で囲み、`tbody` 内の有効な移動先となる行間に水平の挿入線を表示する。

有効な移動先で操作を完了すると、その位置へ行を移動する。

### 5.2 列

列並び替えモード中は、Table 全体の列そのものを並び替え対象として操作する。

並び替えを開始していない通常操作では、Table や編集画面を通常どおりスクロールできるようにする。列から DnD を開始した後は、移動対象の列を線で囲み、Table 全体の有効な移動先となる列間に垂直の挿入線を表示する。

有効な移動先で操作を完了すると、その位置へ列を移動する。

## 6. DnD 中の表示と移動

### 6.1 ドラッグ中の行・列

DnD が開始されたら、現在の移動対象を線で囲み、DnD が開始されたことと移動対象を視覚的に示す。

ドラッグ中の行・列は、元の Table 上にあるときの大きさとセルの配置関係を保って表示する。

行をドラッグする場合は、空のセルを含んでいても行全体の横幅や各セルの幅が不自然に縮まないようにする。また、ドラッグ中の行が Table の横方向から不必要にはみ出さないようにする。

列をドラッグする場合も、空のセルを含んでいても列全体の幅や各セルの高さが不自然に縮まないようにする。また、ドラッグ中の列が Table の縦方向から不必要にはみ出さないようにする。

これらの表示範囲の制約によって、移動に必要な自動スクロールは妨げない。

### 6.2 Preview と移動先

DnD 中は、Table 上の行・列の実際の順番を変更しない。移動対象、現在の移動先を示す挿入線、移動先の変化に応じた周囲の行・列の表示を更新する。

現在の有効な移動先を挿入線で示す。行の並び替えでは `tbody` 内の行間に水平の挿入線を表示し、列の並び替えでは Table 全体の列間に垂直の挿入線を表示する。移動先が変わると、挿入線も現在の移動先へ移る。

移動先が変わった場合は、移動対象が入る空間を空けるように、位置が変わる周囲の行・列を滑らかに移動させる。位置が変わらない行・列は、この移動に合わせて一斉に動かさない。

行 DnD では `tbody` 内の構造、列 DnD では Table 全体の構造を保てる位置だけを有効な移動先として扱う。結合セルなどのために移動すると対象範囲の構造が成立しなくなる位置では、確定可能な移動先を示す挿入線を表示せず、並び替えを確定しない。

### 6.3 自動スクロール

Table が画面内に収まらない場合でも、移動方向に沿って並び替えを続けられるようにする。

行の DnD 中は、行の移動に必要な縦方向だけを自動スクロールし、横方向には自動スクロールしない。

列の DnD 中は、列の移動に必要な横方向だけを自動スクロールし、縦方向には自動スクロールしない。

DnD を開始していない通常状態では、この制限を適用せず、Table や編集画面を通常どおりスクロールできるようにする。

### 6.4 確定・キャンセル

有効な移動先でドロップして DnD が完了した場合だけ、その時点で Table の順序を更新する。確定時は、移動対象を最終位置へ滑らかに移動させ、並び替え後の配置へ自然につなげる。

操作がキャンセルされた場合は、移動対象を元の位置へ自然に戻し、Table のデータを変更しない。

移動先が成立しない場合、または有効な位置へドロップされなかった場合も、Table のデータを変更しない。

### 6.5 継続できない場合の安全な終了

DnD 中に Editor や Table の状態が変化して並び替えを継続できなくなった場合、または Reorder の処理中にエラーが発生した場合は、その並び替え操作を終了する。

終了時は、移動対象の強調、挿入線、周囲の行・列の移動表示など DnD 中だけの表示を解除し、利用者がその時点の Table の状態から通常の編集を続けられる状態へ戻す。

継続できなくなった操作を新たに並び替え結果として確定しない。Table の更新がすでに反映された後に操作を継続できなくなった場合は、終了処理によってその更新を自動的に元へ戻さず、その時点の Table の状態から編集を継続できるようにする。

異常状態の分類、検出、復旧方法、記録など、内部での具体的な実現方法は Architecture で定義する。

## 7. 並び替え後の状態

並び替えが成立した場合、移動した行または列の位置だけを変更し、セルの内容、属性、装飾その他の保持すべき情報は維持する。行 DnD では `tbody` 内の行順だけを変更し、列 DnD では Table 全体の列順を変更する。

セル内容がテキスト、画像、RichText その他の内容であっても、行・列の並び替えの扱いは変えない。セル内容そのものは変更せず、行または列の位置だけを変更する。

`FR-13` で定義する対応 Table Block のいずれでも、利用者から見た操作と結果は同じ方針とする。

一回の並び替えは、一回の Undo 操作で並び替え前の順序へ戻せるようにする。

## 8. 大規模 Table

### 8.1 前提

大規模 Table の判定基準、想定最大規模、および Performance の保証範囲は、Quality Requirements の `QR-01 Performance` に従う。

### 8.2 利用時の振る舞い

Table が大きい場合でも、並び替えの入口、移動対象、現在の移動先を示す挿入線、確定後の結果を確認できる状態を維持する。

移動先が変わったときに滑らかに移動させる対象は、実際に表示位置が変わる行・列とし、無関係な行・列まで一斉に動かさない。
